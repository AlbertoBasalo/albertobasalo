## // AI-Driven Development

Metodología para usar IA durante todo el ciclo de desarrollo sin perder control, calidad ni mantenibilidad.

| | |
| --- | --- |
| **Human in the Loop** | El programador sigue tomando las decisiones importantes. La IA acelera el desarrollo. |
| **Rules Over Tools** | La productividad no depende del agente, sino del contexto y las reglas que recibe. |
| **Spec Driven Development** | Especificaciones claras para alinear agentes, programadores y negocio. |
